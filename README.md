# ओजस क्लिनिक वेबसाइट — सेटअप मार्गदर्शक

वेबसाइटमध्ये: मराठी मुख्य पान, ऑनलाइन अपॉइंटमेंट (टोकन क्रमांकासह), रुग्णासाठी "माझी अपॉइंटमेंट तपासा",
स्टाफसाठी तारखेनुसार रजिस्टर (`admin.html`), आणि QR कोड (बुकिंग, कॉल, Instagram रिव्ह्यू, YouTube).

```
ojas-website/
├─ index.html      मुख्य वेबसाइट
├─ admin.html      स्टाफ लॉगिन + तारीखनिहाय अपॉइंटमेंट यादी, स्थिती, CSV डाउनलोड
├─ qr.html         क्लिनिकमध्ये लावण्यासाठी A4 QR पोस्टर (प्रिंट करा)
├─ config.js       फोन, Instagram, YouTube, API_URL — फक्त ही फाइल बदला
├─ styles.css, assets/   (assets/ojas-promo.mp4 = वेबसाइटवरील प्रोमो व्हिडिओ)
├─ qr-codes/       कॉल व Instagram QR (PNG, प्रिंटसाठी)
└─ backend/        Code.gs + appsscript.json (Google Sheet डेटाबेस)
```

---

## पायरी 1 — डेटा कुठे साठवला जातो (सुरक्षित बॅकएंड)

सर्व अपॉइंटमेंट क्लिनिकच्या **स्वतःच्या खाजगी Google Sheet** मध्ये साठवल्या जातात.
Sheet फक्त क्लिनिकच्या Google खात्यालाच दिसते; वेबसाइटवरून कोणालाही ती थेट उघडता येत नाही.

1. क्लिनिकच्या Gmail (**ojashospital2025@gmail.com**) ने https://sheets.new उघडा → नाव द्या: **Ojas Appointments**.
2. मेनू **Extensions → Apps Script**.
3. `Code.gs` मधील सर्व मजकूर पुसा आणि `backend/Code.gs` मधील कोड पेस्ट करा.
4. डावीकडे ⚙ **Project Settings** → "Show appsscript.json" ✔ → Editor मध्ये `appsscript.json` उघडून `backend/appsscript.json` पेस्ट करा (वेळ क्षेत्र Asia/Kolkata).
5. वर फंक्शन यादीत **setup** निवडा → **Run** → परवानगी द्या (Advanced → Go to project → Allow).
6. `setAdminPassword` फंक्शनमध्ये `NEW_PASSWORD` च्या जागी किमान 8 अक्षरी मजबूत पासवर्ड लिहा → **Run** →
   **मग तो पासवर्ड कोडमधून पुसून Save करा.** (पासवर्ड hash स्वरूपात साठवला जातो.)

## पायरी 2 — API चालू करा

1. **Deploy → New deployment** → प्रकार **Web app**.
2. Execute as: **Me**, Who has access: **Anyone** → **Deploy**.
3. मिळालेली **Web app URL** (`https://script.google.com/macros/s/.../exec`) कॉपी करा.
4. `config.js` मध्ये `API_URL: "..."` येथे पेस्ट करा.
5. YouTube चॅनेलची लिंक `YOUTUBE_URL` मध्ये टाका.

> कोड बदलल्यास: Deploy → Manage deployments → ✏ → Version: New version → Deploy (URL तीच राहते).

## पायरी 3 — वेबसाइट ऑनलाइन करा (मोफत)

**पर्याय A — GitHub Pages**
1. GitHub वर नवीन public repository बनवा, उदा. `ojas-clinic`.
2. `ojas-website` फोल्डरमधील सर्व फाइल्स (backend फोल्डर ऐच्छिक) अपलोड करा.
3. Settings → Pages → Branch: `main` / root → Save.
4. 1–2 मिनिटांत साइट: `https://<username>.github.io/ojas-clinic/`

**पर्याय B — Netlify**: https://app.netlify.com/drop वर `ojas-website` फोल्डर ड्रॅग करा.

## पायरी 4 — QR कोड

- वेबसाइट ऑनलाइन झाल्यावर `https://.../qr.html` उघडा → **पोस्टर प्रिंट करा**.
  बुकिंग QR आपोआप तुमच्या वेबसाइटच्या पत्त्यावरूनच बनतो, त्यामुळे तो नेहमी योग्य असतो.
- `qr-codes/` मध्ये कॉल व Instagram चे उच्च गुणवत्तेचे PNG आहेत (फ्लेक्स / स्टिकरसाठी).

## रोजचा वापर (स्टाफ)

- `https://.../admin.html` → पासवर्ड → आज / उद्या / 7 दिवस / मागील 30 दिवस / हवी ती तारीख.
- यादी तारखेनुसार, नंतर सकाळ → दुपार → संध्याकाळ, नंतर टोकन क्रमांकानुसार लावलेली असते.
- प्रत्येक रुग्णाची स्थिती बदला: प्रतीक्षेत / निश्चित / तपासणी झाली / रद्द / आले नाहीत; नोंद लिहा.
- **Excel (CSV) डाउनलोड** — निवडलेल्या तारखांची यादी Excel मध्ये उघडते.
- संपूर्ण डेटा Google Sheet मध्येही नेहमी उपलब्ध (बॅकअप: File → Download → Excel).

## सुरक्षा व्यवस्था

| धोका | उपाय |
|---|---|
| कोणीतरी रुग्णांची यादी पाहणे | यादी फक्त ॲडमिन टोकनने (HMAC स्वाक्षरी, 8 तास वैधता) |
| पासवर्ड चोरी | पासवर्ड साठवला जात नाही, फक्त salted SHA-256 hash |
| पासवर्ड अंदाज लावणे | 5 चुकीचे प्रयत्न → 15 मिनिटे लॉगिन बंद |
| स्पॅम / बनावट बुकिंग | मोबाईल पडताळणी, तासाला मर्यादा, एका नंबरवर कमाल 3 सक्रिय अपॉइंटमेंट, बॉट-ट्रॅप |
| डुप्लिकेट बुकिंग | एकाच नंबरवर एकाच दिवसाची दुसरी नोंद होत नाही |
| एकाच वेळी बुकिंग | LockService — टोकन क्रमांक कधीच दुप्पट होत नाही |
| Sheet मध्ये धोकादायक मजकूर | फॉर्म्युला-इंजेक्शन व HTML काढून टाकले जाते |
| रुग्णाने स्वतःची माहिती पाहणे | ID + मोबाईल दोन्ही जुळले तरच स्थिती दिसते |

`admin.html` शोध इंजिनमध्ये येऊ नये म्हणून `noindex` आहे. पासवर्ड बदलण्यासाठी पायरी 1.6 पुन्हा करा (सर्व जुने लॉगिन आपोआप रद्द होतात).
